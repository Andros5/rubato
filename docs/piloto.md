# Piloto con un mantenedor externo (preparado, pendiente)

**Objetivo.** Validar usabilidad, no disposición a pagar.

**Perfil.** Una persona que mantenga otra automatización con IA y límites de proveedor.

**Sesión (≈ 60 min, grabación opcional con consentimiento).**
1. Instalar el simulador siguiendo solo `README.md` (cronometrar).
2. Convertir su carga o un ejemplo representativo a `rubato.trace/v1`
   (`docs/trazas.md`), o usar `rubato synth` si no puede compartir datos.
3. Elegir el compromiso entre espera del fondo y cuota reservada con la rejilla de
   `simulate` y el informe.
4. Explicar sin ayuda por qué se aplazó una tarea concreta (`explain` o la ficha).

**Medidas.** Tiempo hasta el primer informe; tiempo de conversión de la carga; acierto
al explicar la decisión (sí/no y en qué se equivocó); conceptos que faltaron o
confundieron; errores del cargador que no entendió.

**Registro.** Añadir el resultado a `ESTADO.md` (F8) sin datos personales del piloto.

**Estado.** No celebrado: requiere una persona externa. El paquete reproducible está
listo para la sesión.
