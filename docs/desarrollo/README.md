# Development notes

Working notes kept while building Rubato, in Spanish.

- [`PLAN_RUBATO.md`](PLAN_RUBATO.md): the original plan, from F0 (repository and first
  acceptance case) to F8 (v1 release). It covers the specification, the order of work
  and the closing criteria of each phase.
- [`ESTADO.md`](ESTADO.md): the phase log. For every phase it records the exact
  commands, their results, the evidence and the criteria still waiting on real
  traffic or on a person.

They are kept in the repository on purpose. They show how each claim in the README was
checked, and which ones are still waiting for evidence.
